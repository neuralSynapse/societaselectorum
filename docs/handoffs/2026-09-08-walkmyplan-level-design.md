## Intended encounter flow

Threshold Hall -> First Combat Court, with optional east/west Guard Chambers -> Second Combat Court, with optional east/west Reliquaries -> Reward Shrine / Boss Antechamber -> north boss gate/exit.

The central route uses wide double doors for readable FPS combat flow. Side chambers provide optional encounter/reward branches without forcing corridor-heavy navigation. The upper area separates reward and boss staging so future roguelite choices can be represented spatially before a boss encounter.
