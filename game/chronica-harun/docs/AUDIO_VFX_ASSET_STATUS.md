# CHRONICA HARUN · Audio/VFX Asset Status

Branch: `feat/chronica-audio-vfx-v1`

## Classification rule

- **final**: original/licensed asset with final production approval.
- **candidate**: installed authored asset that may replace a placeholder after review.
- **placeholder**: procedural/runtime stand-in used to preserve feedback and boot safety.

## Audio

No final licensed/original audio files are present in the current base tree. `AudioDirector` therefore resolves every gameplay SFX ID to an original procedural `AudioStreamWAV` fallback. All current synthesized sounds are **placeholder** assets. If an authored file is later installed at an `EVENT_SPECS.path`, it resolves as **candidate** until explicitly promoted by production review.

Current resolved IDs include player primary/power/hit, Kinesis, Instrumenta, Tarot, enemy windup/shot/hit/death, projectile impact, boss windup/attack/phase/death, pickup, secret rupture audio (`secret_break`), special-room activation, footsteps, dodge and power reveal.
